# 食光知味（Savoria） - 商户后台

> 时光知味，岁月沉香

**食光知味** —— 用心烹饪，让每一刻时光都值得回味。

---

这是独立的 PC 商户后台原型目录。

当前实现方式：
- Vue 3 + Vite 构建
- 响应式后台管理界面
- 直接打开 [index.html](D:/develop/Project/Kitchen/admin-web/index.html) 即可预览
- 已提供 `api-client.js` 作为后续接入 Spring Boot 后端的统一请求层

## 核心功能

### 📊 工作台
- 经营数据概览
- 快捷操作入口

### 📦 订单管理
- 查看订单详情、推进状态
- 调整配送费、取消订单并记录原因

### 🍳 菜品管理
- 新增 / 编辑菜品
- 上下架切换
- 查看商户制作流程

### 🥬 食材管理
- 新增 / 编辑 / 删除可移除食材
- 被引用食材禁止删除

### 👨‍👩‍👧‍👦 家庭管理
- 查看家庭详情
- 调整配送开关、免配送和默认配送费
- 维护家庭共享地址簿
- 成员余额管理

### 📋 采购清单
- 勾选采购项
- 查看采购来源
- 补录临时采购

### 🔔 通知中心
- 过滤通知、查看详情
- 商户消息一键标记已读
- 跳转到对应订单 / 采购 / 家庭余额

## 技术栈

- **前端框架**: Vue 3
- **构建工具**: Vite
- **状态管理**: Pinia
- **路由**: Vue Router
