# 后端联调说明

## 1. 数据来源

后端禁止模拟登录和模拟业务数据。联调必须连接真实 MySQL，并通过正式接口创建数据：

1. 启动 MySQL 8，创建空的 `family_kitchen` 数据库。
2. 启动后端，由 Flyway 执行 V1-V3。
3. 使用 `application.yml` 配置的初始化管理员登录。
4. 普通用户通过注册、账号登录或真实微信登录进入系统。
5. 通过管理员和商户接口创建商户、家庭、菜品、菜单等联调数据。

不得再使用 `member-demo`、`merchant-demo`、`platform-demo` 等固定 code。

## 2. 推荐联调顺序

### 平台端

1. 管理员登录。
2. 配置站点名称、Logo、维护模式、菜品审核和账号绑定开关。
3. 创建或审核商户，并分配后台权限。
4. 审核家庭和菜品申请。

### 家庭端

1. 注册或登录用户。
2. 创建家庭或接受邀请；同一用户只能保留一个有效家庭关系。
3. 查询家庭首页、地址、餐次和家庭菜单。
4. 加入当天指定餐次的共享餐篮并填写备注。
5. 提交订单并查询订单状态、钱包流水和通知。

### 商户端

1. 登录具有商户后台权限的真实用户。
2. 维护菜品分类、食材字典、菜品和制作流程。
3. 配置家庭菜单和专属价格。
4. 确认订单、调整配送费、推进状态或填写原因取消。
5. 查询采购清单；待确认订单来源显示为预估，已确认来源显示为确认。

## 3. 图片上传

`POST /api/files/images`

- multipart 字段名：`file`
- 支持类型：`jpeg/png/webp`
- 大小限制：`4MB`
- 默认存储目录：`backend/uploads/images/`
- 静态访问路径：`/uploads/images/{fileName}`

## 4. 注意事项

- 当前运行时只保留 MyBatis/MyBatis-Plus 数据库实现。
- 家庭端菜单读取家庭菜单配置，不直接读取商户全部菜品。
- 被停用或不属于该家庭菜单的菜品，后端会拒绝加入餐篮。
- 菜品制作步骤仅商户端和有权限的后台可见。
- 所有联调记录都会真实写入数据库，需要清理时通过业务接口处理或重建开发库。
