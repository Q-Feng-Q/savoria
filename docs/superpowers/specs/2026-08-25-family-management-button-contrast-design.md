# 家庭管理页按钮对比度修复设计

## 背景

家庭管理页引用了当前暖厨主题未定义的 `--sk-coral` 和 `--sk-ink`。前者用于主按钮，后者还用于 hero、负责人区和邀请码边框。微信小程序会丢弃包含无效变量的颜色声明，使按钮退回透明或继承色，最终与暖白、浅绿背景混在一起。

## 范围

仅修改家庭管理页的 WXML、WXSS 及其页面级视觉契约测试。不修改全局主题 token，不改变按钮业务行为、权限、接口或页面结构。页面根节点声明 `--fm-*` 专用颜色变量，并用 `--fm-ink` 替换该页面所有未定义的 `--sk-ink` 引用。

## 视觉方案

- 主操作（保存、生成邀请码、发送邀请、确认移交）：深珊瑚棕 `#9f4f3d` 背景、白色文字、同色边框。
- 次操作（编辑、取消、地址管理）：暖白背景、深咖啡 `#4f392f` 文字、`#9b765f` 边框。
- 正向小操作（接受、通过）：深鼠尾草绿 `#55705c` 背景、白色文字、同色边框。
- 普通小操作（拒绝）：暖白背景、深咖啡文字、清晰边框。
- 危险操作（退出、解散）：浅红 `#fff0eb` 背景、深红 `#a63f35` 文字和边框。
- 禁用状态：所有具备 busy/saveBusy/transferBusy 的按钮在 WXML 中显式附加 `.is-disabled`，使用 `opacity: .58`，保留原背景、文字与边框色；不使用微信 WXSS 兼容性不稳定的属性选择器或滤镜。
- 按压状态：不再降低整颗按钮透明度，使用轻微缩放与内阴影表达按压，避免文字对比度随背景混合而下降。

所有按钮在常规宽度及 320/360px 小屏均保持至少 88rpx 的触控高度。现有文件末尾的覆盖规则会合并回各按钮声明块，避免测试只匹配到无关的 88rpx。

## 验证

- 契约测试禁止家庭管理页继续引用 `--sk-coral` 或 `--sk-ink`，并检查页面级 `--fm-*` 变量存在。
- 契约测试按具体选择器检查主、次、正向、普通拒绝、危险、禁用和按压状态，分别具备明确的背景色、文字色、边框或反馈规则。
- 正常态文字对比度以 WCAG AA 4.5:1 为最低标准：主按钮约 5.74:1、正向约 5.44:1、次按钮约 10.54:1、危险按钮约 5.59:1。按压态不改变透明度；禁用态仍需保持轮廓、底色与标签可辨识。
- 契约测试逐类断言 `.section-quiet-action`、`.profile-action`、`.section-link`、`.transfer-action`、`.block-action`、`.invitation-code`、`.mini-action`、`.danger-action` 的最小高度为 88rpx。
- 使用微信开发者工具或等价渲染检查 320px、360px、系统大字体/文字缩放和底部安全区，覆盖暖白与浅绿承载背景，确认无横向溢出、按钮标签不截断；工具不可用时明确记录该项未执行。
- 运行家庭管理页相关测试及完整小程序测试。
- 运行 JavaScript 语法检查与 `git diff --check`。
