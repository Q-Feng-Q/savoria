# 记事系统模板库与用户投稿设计

日期：2026-10-03
状态：方案已由用户确认，待规格复核

## 目标与边界

在现有个人记事模块内预置 20 个中文起始模板，并支持用户从零创建「我的模板」或将自己事件的当前字段版本另存为模板。用户可提交自己的模板供平台管理员审核；通过后，所有用户可从系统模板库选用。模板是字段结构的起点，不是记录容器。选用模板时创建归属于当前账号的新事件及其模板版本 1；系统模板或原个人模板后续变化不自动改变该事件、历史版本或记录。

本功能不得上传、展示或发布任何记事记录、字段值、图片、联系人、共享设置或私密事件描述。平台管理员可看投稿的模板名称、分类、说明和字段定义，但仍不能读取用户记事正文。用户的模板及事件归账号，不归家庭。模板库属于 `notebook` 独立模块，不复用菜品模板表或流程。

不含提醒、周期预测、统计分析、医疗建议、模板自动同步、跨用户协作编辑模板、公开评论或模板市场搜索排序。已有事件可继续自由编辑字段并按现有规则发布新版本，历史记录保持原样。

## 产品流程与状态

小程序「记事」增加「模板库」入口，分为「系统模板」和「我的模板」。系统模板按分类浏览并可查看字段预览，选用后进入创建事件流程，用户能在保存前修改名称、分类和字段；不直接产生记录。新建事件页同时提供明确的「导入模板」入口，可选择已上架系统模板或自己的模板，将其名称、分类、说明和字段定义预填到当前未保存事件表单；用户可继续编辑后保存为事件模板版本 1，也可完全不导入、从空白创建。若当前表单已有未保存输入，导入前须确认会替换这些输入；取消确认则原表单保持不变。导入不携带记录、图片文件、联系人、共享授权或来源模板的后续更新关系。我的模板可新建、查看、修改、删除、从自己的事件当前版本另存、用于创建事件以及提交审核。另存不复制任何记录或权限数据。删除我的模板不删除由它创建的事件，也不撤销已提交或已上架的快照。

投稿使用不可变的提交快照，状态为 `PENDING`、`APPROVED`、`REJECTED` 或 `WITHDRAWN`。提交时只复制模板名称、分类、说明及合法字段定义，不包含来源事件 ID、用户字段值或附件。用户可在待审时继续编辑私有模板；待审快照不随之改变。用户可查看自己的投稿状态和驳回原因，并可撤回待审投稿。同一私有模板在任意时刻最多有一个待审投稿；待审期间再次提交返回冲突。驳回、撤回或通过后才可再次提交，因此同一模板的投稿按提交顺序进入审核，不会出现旧快照在新快照后通过。重新提交与最近一次已通过快照完全相同的内容时拒绝重复投稿。

管理端新增记事模板审核页，只显示投稿者账号标识、提交时间、模板结构和状态，不提供事件或记录入口。管理员可通过或填写原因驳回。通过时以该快照创建或发布系统模板，原投稿成为已通过状态；审核操作记录操作者和时间。审核遇到已撤回或已处理状态返回冲突，不重复发布。管理端可下架已上架模板；下架只阻止新的选用，不影响现有事件。用户不得自行直接全平台发布。

已上架模板若投稿者再次修改并提交，作为该系统模板的新候选版本审核；通过后新用户选用最新版本，既有事件副本不自动更新。系统模板版本不可原地修改。用户的其他私有模板提交后，审核通过则创建新的系统模板，不凭同名自动合并。首批 20 个模板由数据库前向迁移初始化，保留稳定的系统标识，重复部署不应重复插入。

## 数据和接口边界

后端实体集中在 `com.familykitchen.notebook`，表以 `notebook_` 开头，使用新的 Flyway 前向迁移，不修改已经应用的迁移。区分个人模板、个人投稿快照、系统模板及其不可变版本。所有权从登录会话读取，不能由请求体指定。字段定义复用现有 `NotebookTemplateValidator` 的类型、数量、选项和长度约束；创建事件时由服务端重新生成适用于新事件的字段 `key`，不继承来源事件内部字段键。

小程序网络接口归入现有 `frontend/services/notebook.js` 门面；页面归入 `frontend/pages/notebook/`。管理端 API 放在独立的记事模板审核客户端模块和平台视图中。公开目录接口只返回已上架系统模板的结构；我的模板及投稿仅所有者可见。管理端审核接口要求平台管理员权限，不能复用记事正文读取接口。`docs/api-spec.md` 同步增加目录、我的模板、投稿和审核端点及状态契约。

## 异常、安全与测试

所有服务端读写再次验证身份和所有权。投稿时剔除来源事件/记录关联并只持久化白名单字段，不能依靠前端隐藏敏感字段；审核页和日志也不能泄露记录值。模板名称、说明和选项作为用户内容进行长度校验和安全显示。审核操作须防并发重复发布。选用已下架、无效版本或已删除模板时提示刷新；创建事件失败不能留下半成品事件。系统模板目录不可用时保留从零创建事件的能力。我的模板修改失败保留本地草稿或输入，投稿失败不改变个人模板。

验收测试覆盖：20 个初始模板完整且字段类型合法；从模板库选用或在新建事件页直接导入模板均可创建独立事件，且导入后可编辑、已有未保存内容替换前需确认、取消时不丢失输入；从零创建及从当前事件版本另存；个人模板更新不改变投稿快照、系统模板和既有事件；审核通过、驳回、撤回、重复审核与下架；普通用户不能审核或查看他人私有模板；投稿与管理端响应绝不含记录正文、附件、联系人或共享设置。运行相关小程序、管理端和后端测试及管理端构建。
