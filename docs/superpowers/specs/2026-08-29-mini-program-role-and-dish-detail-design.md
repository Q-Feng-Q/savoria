# 小程序角色称呼与菜品详情优化设计

## 目标

统一家庭端所有角色称呼，消除“小熊主厨”等固定动物角色文字；调整点菜步进按钮位置，并提升菜品详情的可读性。

## 角色称呼

- 使用首页接口 crew 返回的真实名称。
- 有名称时显示“名称 + 角色”，例如“老祁主厨”“阿禾帮厨”“小林试吃员”。
- 无名称时分别显示“无主厨”“无帮厨”“无试吃员”，不得产生“无主厨主厨”。
- 首页、点菜页、个人中心和主厨推荐文案使用同一个格式化结果。
- 动物插画与角色徽章可以保留，但用户可见文字不得再出现“小熊主厨”“兔子帮厨”“橘猫试吃员”或“小熊今日推荐”。

## 点菜列表

- 菜品卡片的数量步进器保持现有 38rpx 视觉按钮。
- 将步进器整体向卡片底部移动，避免遮挡菜品介绍和标签。

## 菜品详情

- 顶部分类不显示内部分类 ID。接口提供分类名称时显示名称，否则显示“今日菜单”。
- 价格区域只显示一个“家庭价格”，不显示商户基础价。
- 增加“点餐信息”和“主要食材”等清晰标题。
- 标题、说明文字和内容面板之间使用明确的上下间距与分隔线，保持暖色动物私厨视觉风格。

## 验证

- 场景映射测试覆盖角色后缀、缺失角色回退和分类名称回退。
- 页面契约测试覆盖固定动物称呼消失、详情单一价格、分区标题和步进器下移。
- 运行全部小程序 Node 测试。
